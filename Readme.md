# 🌸 Pixora – Share & Discover Creative Inspiration

Pixora is a modern media gallery platform inspired by Pinterest, built to help users share, explore, and discover beautiful images, artworks, and creative ideas.  
It provides a smooth and interactive experience for both creators and viewers, along with an admin dashboard for managing user content.

---

## 🚀 Features

### 👤 User Features
- User authentication (Sign up / Sign in)
- Upload and share creative posts
- Explore trending and recent posts
- Like, save, and comment on posts
- Get notified when a post is approved or rejected
- View and manage your uploaded posts
- Responsive and modern UI with Tailwind CSS

### 🛠️ Admin Features
- Secure admin authentication
- Manage users and their posts
- Approve or reject submitted posts
- Monitor platform activity via dashboard
- Maintain quality and community standards

## 🧰 Tech Stack

### **Frontend**
- [Next.js](https://nextjs.org/) – React framework for building fast, scalable web apps  
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework for modern UI design  

### **Backend**
- [Express.js](https://expressjs.com/) – Lightweight and flexible Node.js web framework  
- [Node.js](https://nodejs.org/) – JavaScript runtime environment  
- [Prisma](https://www.prisma.io/) – Modern ORM for efficient database management
